# أكسل هاب أكاديمي — Bridge Academy

## القواعد المطبّقة
- 6 مستويات، وحدتان في كل مستوى (12 وحدة إجمالًا).
- لا يوجد رسوب أو حد أدنى للدرجات، ولا إعادة تلقائية للمستوى.
- المدرّس المعيّن للجروب يسجّل إتمام الوحدتين ويكتب فيدباك ثم يؤكد إتمام المستوى.
- التأكيد يحفظ الفيدباك ويرفع المستوى فورًا. الإدارة تعيّن جروب المستوى الجديد؛ لا يتم اختيار المدرّس أو المواعيد تلقائيًا.
- المستوى السادس ينتهي بحالة إتمام البرنامج؛ لا يُنشأ مستوى سابع.
- ولي الأمر يقرأ سجل أولاده المرتبطين بحسابه فقط؛ الطالب يقرأ سجله فقط.
- الفيدباك ظاهر داخل الحساب، وليس رسالة بريد تلقائية.

## التجربة والتحديث
هذه إضافة إلى التطبيق الموجود؛ لم تُنشر أو تُنفّذ على Codespaces بعد.
قبل دمج الفرع، احتفظ بتغييرات تجربة Codespaces المحلية، خاصة إصلاح روابط المعاينة.
راجع git status ولا تستخدم reset --hard. ملف .env سري ولا يُرفع إلى GitHub.
خذ نسخة احتياطية من قاعدة البيانات وملفات الرفع، واختبر على نسخة تجريبية أولًا.

بعد دمج التغييرات في نسخة التطبيق:

```bash
php artisan migrate --force
php artisan config:clear
php artisan view:clear
php artisan test --filter=AcademyWorkspaceTest
```

افتح /academy. لا تحتاج npm build لهذه الشاشات؛ التنسيق مستقل عن حزمة Vue القديمة.
الحسابات الموجودة تستخدم نفس تسجيل الدخول. بعد تسجيل دخول جديد، المدير والمدرّس
والطالب وولي الأمر يتجهون إلى المساحة الجديدة. الحسابات الإدارية الأخرى تحتفظ بوجهتها.
يمكن تعطيل تحويل الدخول والقائمة الجديدة بوضع ACADEMY_ENABLED=false ثم config:clear.
التعطيل لا يحذف الجداول؛ تبقى /academy متاحة للحسابات المصرح بها.

## الاستخدام
1. المدير ينشئ الجروبات ويختار مستوى ومدرّسًا ومواعيد لكل جروب.
2. يضيف الطلاب الحاليين للجروب. أول تسجيل يحدد مستوى البداية، للسماح بتسكين الطلاب الحاليين.
3. النقل بين الجروبات مسموح في نفس المستوى، دون تصفير التقدّم.
4. المدرّس يفتح جروبه، يحفظ إتمام الوحدات، ثم يكتب الفيدباك ويؤكد الانتقال.
5. الطلاب المنتقلون يظهرون للإدارة في قائمة انتظار جروب المستوى التالي.
6. الطالب وولي الأمر يشاهدان السجل من /academy. ربط ولي الأمر بالطالب يتم من إدارة الحسابات القديمة.

الجروب يُؤرشف بدل الحذف النهائي؛ الجروب الذي يحتوي على طلاب لا يُؤرشف قبل نقلهم.
الفيدباك المنشور سجل ثابت لا يتغير بتغيير مدرس الجروب أو أرشفته.

## نطاق التكامل
المساحة الجديدة تستخدم حسابات المستخدمين والربط الحالي بين الطالب وولي الأمر.
لا تعيد تسمية أو حذف الفصول والسنوات أو الجداول القديمة، ولا تحوّل بيانات الديمو تلقائيًا.
جروبات المنهج الجديدة ليست بديلًا تلقائيًا عن StandardsLink/Groups القديمة:
الحضور والواجبات والمدفوعات والتقارير القديمة تبقى متاحة من رابط «باقي وظائف الإدارة»
وتستمر على روابطها القديمة. مزامنتها مع جروبات المنهج تحتاج مرحلة تكامل لاحقة.
اسم الأكاديمية في المساحة الجديدة من config/academy.php. لم تتم إضافة شعار رسمي لعدم استلامه.

## التحقق
أضيفت اختبارات للانتقال بدون درجات، إتمام المستوى السادس، تكرار الطلب، شرط إتمام
الوحدتين والفيدباك، عزل الأكاديميات، صلاحيات ولي الأمر والطالب والمدرّس، وأرشفة الجروب.
لم يتم تشغيل PHPUnit أو التطبيق في بيئة التنفيذ الحالية: PHP غير متاح، والوصول
إلى Docker محظور، واتصال Git عبر البروكسي لا يعمل. يجب أن تمر الاختبارات ومراجعة
الحسابات الأربعة على staging قبل دمج هذا التغيير للاستخدام الفعلي.
